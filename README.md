# Gemstone Recommendation App

A rule-based gemstone recommendation web application that suggests gemstones based on the user's zodiac sign and concern.

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS

## Features

- User name input
- Zodiac sign selection
- Concern selection
- Rule-based gemstone recommendation
- Gemstone image display
- Reason, suggested metal, and wearing day display
- Recommendation history
- Delete history record
- Disclaimer for demo purpose

## How It Works

The user enters their name, selects a zodiac sign, and selects a concern such as Career, Education, Love, Health, Money, Business, or Marriage.

Based on predefined rules, the app recommends a gemstone with reason, suggested metal, and wearing day.

## Assumptions

- Recommendations are based on predefined demo rules.
- This app does not perform real astrology calculations.
- This project is created only for evaluation and demonstration purposes.
